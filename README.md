# 문자열 덧셈 계산기

---

## 프로그램 동작 순서

1. 계산기 실행 문구인 `덧셈할 문자열을 입력해 주세요.`를 출력한다.
2. 사용자에게 문자열을 입력받는다.
3. 문자열에서 숫자를 추출하여 더한 값을 출력한다
    - 출력 형식 : `결과 : 6`

---

## 기능 목록

### 입출력

- [X] 계산기 실행 문구인 `덧셈할 문자열을 입력해 주세요.` 출력
- [X] 사용자에게 문자열 입력
- [X] 덧셈한 계산 결과 `결과 : [값]` 형식으로 출력

### 문자열 파싱

- [ ] 커스텀 구분자 존재 여부 확인
    - 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자
    - 예시 : `//;\n1;2;3`의 입력에는 `;`가 커스텀 구분자
- [ ] 구분자를 기준으로 숫자 분리
    - 기본 구분자 (`,`, `:`)와 커스텀 구분자가 있는 경우 커스텀 구분자를 포함

### 계산

- [ ] 분리된 숫자들을 덧셈
- [ ] 입력 문자열이 비어있는 경우 `0`을 반환
- [ ] 숫자가 하나만 입력되는 경우 그대로 반환

---

## 예외 처리

사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료

### 예외 발생 상황

- [ ] 커스텀 구분자가 없을 경우, 기본 구분자(`,`,`:`)가 아닌 다른 문자가 입력될 경우
- [ ] 양수가 아닌 숫자(0을 포함)가 입력되는 경우
- [ ] 커스텀 구분자 태그("//"와 "\n") 안에 2개 이상의 문자가 입력될 경우
- [ ] 커스텀 구분자에 숫자가 입력될 경우
- [ ] `,1,2`, `1,,2`, `1,2,`와 같이 잘못된 형식의 입력의 경우
